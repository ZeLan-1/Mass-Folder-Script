Mass Folder and Sub Folder script with an excel file

This script is used to mass create a number of Folder names with a similar subfolder template

Note: names.txt are the names of the name folder
      sub.txt are the names of the subfolders 

The names of both files should be:

Folder1
Folder2
Folder3
.
.
.

1 name per line
You can put as many names as you want

Using the script instructions 
1.Extract the .rar file
2.Open the folder and go to script folder
3.execute the foldernames.bat file (via Double clicking)
4.Press any key to exit from terminal
